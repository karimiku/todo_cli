# 要件定義書 v1.0 — Head-Only 常時表示

## 1. 背景・目的
- v0 で整備した CLI Todo の体験を、macOS 右上メニューバーに常時表示できるようにする。
- ユーザーはターミナルを開かずに「次にやるタスク」を把握し、1 クリックで完了操作まで完結できることを目指す。
- 既存 CLI の機能（追加・編集・並べ替えなど）は変更せず、常時表示用のエクスポート機能を追加する段階を v1 と定義する。

## 2. スコープ
### 対象
- 新サブコマンド `todo bar --head-only` の実装。
- SwiftBar / xbar から呼び出すことを前提とした出力整形とクリックアクションの付与。
- 表示対象は未完了タスクの先頭 1 件（Head Only）。

### 非スコープ
- 先頭以外の複数タスク表示（複数行タブ）
- Windows / Linux のステータスバー連携（Waybar/Rainmeter 等）
- DB スキーマ変更、通知、Undo/Redo 等の別機能

## 3. ユースケース
1. ユーザーが SwiftBar プラグインを 2〜5 秒間隔で実行し、未完タスクの先頭を常時表示する。
2. 右上アイコン（タイトル行）をクリックすると `todo next` が裏で実行され、タスクが完了状態に移る。
3. 未完タスクが空の場合は祝福メッセージを表示し、クリック操作を無効にする。
4. DB エラーやロックが発生した場合は、エラーメッセージを表示しクリックを無効化する。

## 4. 機能要件
### 4.1 CLI コマンド
| サブコマンド | 説明 |
| --- | --- |
| `todo bar --head-only [--maxlen N] [--icon STR] [--no-tooltip]` | メニューバー向けの 1 行出力を生成する |

#### オプション定義
- `--head-only`（必須）: 先頭タスク 1 件のみを対象とする。
- `--maxlen N`（任意）: タイトル表示の最大文字数。超過時は末尾に `…`（初期値 28 文字）。
- `--icon STR`（任意）: タイトル先頭に付与する記号（既定 `▶️`）。
- `--no-tooltip`（任意）: ツールチップ表示を抑止。未指定時は全文を tooltip に出力。

### 4.2 出力フォーマット
- 未完タスクあり: `▶️ タスク名… | tooltip=全文 bash=todo param1=next terminal=false refresh=1`
- 未完タスクなし: `🎉 空っぽ！ | tooltip=おつかれさま`
- DB エラー: `⚠︎ Error | tooltip=<短文理由>`（クリックアクションは付与しない）
- クリックアクションは `todo next` を非対話 (`terminal=false`) で実行し、`refresh=1` で再描画させる。

## 5. 表示仕様
- タイトル行は UTF-8 の結合文字・絵文字を安全に扱い、`--maxlen` 指定で末尾に `…` を付与。
- tooltip には未省略の全文を表示（`--no-tooltip` 指定時を除く）。
- 未完タスクが 0 件のときはクリック不可状態で祝福メッセージのみを表示する。

## 6. 操作・挙動
- `todo next` は v0 から変えず、RowsAffected == 1 の場合のみ成功とする。
- クリック多重発生や複数プラグイン実行時でも、1 件だけが完了し順序が壊れないようにする。
- コマンドは終了コード 0 を返し、SwiftBar による定期再実行を妨げない。

## 7. データ要件
- DB スキーマは v0 のまま（変更なし）。
- 参照するのは未完了の最上位タスク 1 件のみ。
- `order_key` 劣化時は将来の normalize 対応で補う（v1 非対応）。

## 8. 非機能要件
- CLI 実行時間は 100ms 以内（M1/M2 相当機での単発実行）。
- SwiftBar 更新間隔 2〜5 秒を想定し、CPU 使用率は常時 1〜2% 未満を目標。
- デフォルトでログ出力なし（`TODO_LOG=1` で stderr にデバッグ情報を出す）。

## 9. セットアップ要件
- ユーザーは SwiftBar/xbar のプラグインフォルダにシェルスクリプトを配置し、実行権限を付与。
- 例: `~/Library/Application Support/SwiftBar/Plugins/todo-next.2s.sh`
  ```bash
  #!/bin/zsh
  todo bar --head-only --maxlen 28 --icon "▶️"
  ```
- SwiftBar 側で 2〜5 秒のポーリング間隔を設定する。

## 10. エラーハンドリング方針
| 状況 | タイトル行 | tooltip | クリック |
| --- | --- | --- | --- |
| DB 接続/クエリ失敗 | `⚠︎ Error` | 短文理由（例: `DB busy`） | なし |
| 未完タスク 0 件 | `🎉 空っぽ！` | `おつかれさま` | なし |
| 正常タスクあり | `▶️ xxx…` | 全文（任意で無効化） | `todo next` |

## 11. 受け入れ基準
1. 未完タスクが存在するとき、SwiftBar で 1 行表示されクリックすると `todo next` が実行される。
2. 未完タスクが空の場合、祝福メッセージのみ表示されクリックできない。
3. `--maxlen` 指定で表示が指定文字数に収まり末尾に `…` が付く。
4. `--icon` を変えるとタイトル先頭が置き換わる。
5. DB へアクセスできない場合にエラー表示へ切り替わり、クリックは無効。
6. 多重クリック・同時実行時にタスクが重複完了しない。

## 12. 今後の検討（v1 外）
- 複数タスク表示モード（数件表示 + focus クリック）。
- macOS 以外のステータスバー対応。
- `order_key` normalize の定期実行、Undo/Redo、FTS 検索といった大規模機能。
